ANCIENTS — Dota-inspired fan concept website

1. Extract this ZIP.
2. Open index.html in Chrome, Firefox, Edge, or Safari.
3. To edit the website, open index.html in a code editor such as Visual Studio Code.

Customize:
- Search for "Ancients" to change the brand/title.
- Change headings and paragraphs to suit your project.
- Replace hello@example.com with your email address.
- The hero background image uses an online Unsplash image and requires internet access.

This is an unofficial fan concept, not affiliated with Valve or Dota 2. It is a static front-end website; it does not include game data, accounts, or online features.
